      What these graphs mean
      One sample per second, up to five minutes, held in memory only. GPU counters are device-wide and include other apps. CPU is whole-machine load; read I/O and process RAM belong to this app's backend. Windows read I/O includes cached and non-disk reads.
      Linux/macOS RAM occupancy includes cache; Windows uses OS-unavailable memory. The cache, backend RSS and occupied RAM overlap: do not add them together. OS-reported available RAM includes reclaimable pages, not just free memory, and can be optimistic for driver-pinned pages. macOS availability is estimated as free plus inactive pages. Higher occupancy alone is not faster inference.
      Speed uses real backend timings or output-token counters, never text length. Context uses backend slot occupancy where available; the fallback is reported input plus output tokens, not physical KV-memory use. Missing counters show as unavailable, not zero. NVIDIA monitoring uses the installed driver's NVML library; AMD/Metal GPU sensors are not yet supported. PCIe is sampled driver throughput, not an integrated transfer total.
